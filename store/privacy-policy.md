# 차빼요 개인정보처리방침

**최종 수정일: 2026년 8월 4일**

'차빼요'(이하 "앱")는 이용자의 개인정보를 소중히 여기며, 앱을 제공하는 데
반드시 필요한 최소한의 정보만 처리합니다. 본 방침은 앱이 어떤 정보를 수집하고
어떻게 이용하는지 설명합니다.

## 1. 수집하는 정보

앱은 **이름, 이메일, 전화번호, 주소, 위치정보 등 개인을 식별할 수 있는 정보를
일절 수집하지 않습니다.** 별도의 회원가입이나 로그인 절차도 없습니다.

알림 기능을 제공하기 위해 다음 정보가 처리됩니다.

| 항목 | 내용 | 목적 |
|---|---|---|
| 익명 식별자 | Firebase 익명 인증이 자동 생성하는 임의의 ID | 알림을 보낼 기기를 구분 |
| 기기 알림 토큰 | Firebase Cloud Messaging(FCM)이 발급하는 푸시 토큰 | 해당 기기로 알림 전송 |
| 예약된 알림 정보 | 알림이 울릴 시각과 표시할 문구 | 예약 시각에 알림 발송 |

익명 식별자는 이용자 개인과 연결되지 않으며, 앱을 삭제하고 다시 설치하면
새로운 값이 생성되어 이전 데이터와 연결되지 않습니다.

## 2. 기기에만 저장되는 정보

주차 시각 기록, 주차 횟수, 선택한 주차 제한 시간, 알림 설정은 **이용자의 기기
내부에만 저장**되며 외부로 전송되지 않습니다. 앱을 삭제하면 함께 삭제됩니다.

## 3. 정보의 이용 목적

수집된 정보는 **주차 시간 알림을 정해진 시각에 전송하는 목적으로만** 사용됩니다.
광고, 마케팅, 이용자 분석, 프로파일링 목적으로 이용하지 않습니다.

## 4. 제3자 제공 및 처리 위탁

앱은 이용자의 정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 알림 전송을
위해 다음 서비스를 이용하며, 각 서비스는 해당 목적 범위에서만 정보를 처리합니다.

- **Google Firebase** (Firebase 익명 인증, Cloud Firestore, Cloud Messaging)
  — 제공자: Google LLC / [개인정보처리방침](https://firebase.google.com/support/privacy)
- **Cloudflare Workers** — 예약된 알림을 정해진 시각에 발송하는 서버 역할
  / 제공자: Cloudflare, Inc. / [개인정보처리방침](https://www.cloudflare.com/privacypolicy/)

## 5. 보유 및 파기

예약된 알림 정보는 발송 여부와 관계없이 **생성된 날의 자정(한국 시간)이 지나면
자동으로 삭제**됩니다. 앱을 삭제하면 기기에 저장된 모든 기록이 함께 삭제되며,
이후 서버에 남아 있던 알림 정보도 위 주기에 따라 자동 삭제됩니다.

## 6. 이용자의 권리

앱을 삭제하는 것만으로 기기에 저장된 모든 정보를 즉시 삭제할 수 있습니다.
알림 수신은 앱 내 알림 토글 또는 기기의 알림 설정에서 언제든지 끌 수 있습니다.
서버에 저장된 정보의 삭제를 원하시면 아래 연락처로 요청해 주세요.

수집하지 않습니다.
